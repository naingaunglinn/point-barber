# primitives

shadcn/ui parts generated by the CLI pinned in `VERSIONS.md` (4.21.1, style `radix-nova`, base colour
`neutral`) — add-shared-ui-components task 6.1 · design D1:

```
shadcn add dialog sheet popover tooltip table tabs calendar command radio-group checkbox dropdown-menu sonner skeleton
shadcn add chart        # task 7.27
```

`button`, `input`, `textarea` and `input-group` came in as registry dependencies of those. They are building
blocks of the shared components in `../components`; screens never import them (AD-IMPL-02).

Changed after generation, and only this (re-apply it when a part is generated again):

- **Imports** `@/components/ui/<x>` → `./<x>`.
- **No palette class** (AD-VIS-01): the overlay `bg-black/10` → `bg-foreground/10`.
- **No letter-spacing** (AD-VIS-06): `tracking-widest` removed from the menu shortcuts.
- **Focus and field border through the component variables** (AD-VIS-03 · design D2): the `focus-visible:ring-*`
  / `border-ring` / `outline-ring` classes and `outline-none` on interactive parts are removed, so the 2 px
  `--focus-outline` of `tokens.css` applies; `border-input` → `border-[var(--field-border)]`; an invalid control
  keeps a 2 px `--destructive` outline (D-UI-01) instead of a ring.
- **Touch targets** (AD-A11Y-05 · AD-VIS-07): a tabs trigger is at least 44 × 44 px and 8 px from the next one;
  the list grows with them (no fixed `h-8`) and wraps. The trigger's own 1 px `focus-visible:outline-1` is
  removed, so the 2 px `--focus-outline` applies.
- **Sheet overlay** (`sheet.tsx`): the `backdrop-blur-xs` is removed, so the list beside a drawer stays readable
  under the 10 % dim (AD-CMP-08 "in context", group 10 case "Drawer on desktop and sheet on a phone").
- **Command search** (`command.tsx`, the searchable reason list): the input group is 48 px tall on a phone and
  40 px from 768 px (as `SearchInput`), the input fills its height, and the input's `outline-hidden` is removed, so the 2 px `--focus-outline`
  shows (group 10, checklist items 2 and 3). `input-group.tsx`: the invalid outline colour class had lost its
  `has-[…]:` prefix and is restored.
- **Inputs stay at 16 px** (AD-VIS-06: no iOS zoom): `md:text-sm` removed from `input` and `textarea`.
- **No locale formatting outside the formatter** (AD-FMT-00): the calendar's month-dropdown formatter
  (`toLocaleString`) is removed; the caption label of react-day-picker is used; the day button's
  `data-day` is the day's ISO date (`day.isoDate`) instead of `toLocaleDateString()`.
- **Chart** (`chart.tsx`): the `outline-hidden` of the chart surface, layers and sectors is removed — the chart takes
  keyboard focus, so the 2 px `--focus-outline` must show (group 10, checklist item 3); the class overrides that
  matched Recharts' default strokes `#ccc` / `#fff` are removed
  (the chart components set token strokes), the tooltip writes `String(value)` instead of `toLocaleString()`,
  and the `.dark` theme entry is dropped.
- **No dark mode** (the system has one light theme per tree): every `dark:` class removed, and the toaster no
  longer reads `next-themes`.
- **No literal UI text** (CG-I18N-01): the close labels of `dialog` and `sheet` come from `common.action.close`.

The `data-open:` / `data-checked:` … variants come from `../../primitives.css`; the animations from
`tw-animate-css`.
